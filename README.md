## Overview
Implementation and analysis of learned index structures vs. traditional indexing, evaluating performance, prediction error, and distribution impact across synthetic and real-world datasets.
### We compare:
- Binary Search (baseline)
- B-Tree Index
- Linear Learned Index
- Two-stage Recursive Model Index (RMI)

Focusing on the following metrics:
- Lookup latency
- Prediction error
- Correction cost (last-mile search)
- Memory usage

Datasets: 
- Uniform (ideal case)
- Zipf (skewed distribution)
- Real-world U.S. Baby Names dataset
